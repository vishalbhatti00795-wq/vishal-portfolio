# Vishal Bhatti — Developer Portfolio

Welcome to my personal developer portfolio! This project showcases my technical skills, projects, and ongoing learning journey in programming, machine learning, artificial intelligence, and data analytics.

## About the Project

This is a personal portfolio website built using **HTML5 only**, without CSS, JavaScript, or external frameworks. It demonstrates my understanding of semantic HTML, webpage structure, navigation, and accessible content.
I've recently completed learning HTML5, and this portfolio is my first project built using HTML. I created it to apply what I've learned about HTML elements, semantic structure, navigation, and accessible web content in a practical project.

## Features

- Personal introduction and profile picture
- Technical skills organized into categories
- Featured machine learning and data analytics projects
- Learning and development section
- Contact information and social profile links
- Single-page navigation using HTML anchor links
- Semantic HTML5 elements and accessible markup
